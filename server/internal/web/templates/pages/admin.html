Require email verification for new registrations

When off, new accounts can sign in immediately without confirming an email code. Existing accounts are unaffected.

Allow SSH from the web dashboard

Signed-in users can open terminals in the browser. The SSH session is end-to-end encrypted in the browser; this server only relays the encrypted bytes to the host.

Allow web SSH to private and local addresses

Lets the relay reach LAN, loopback and other private addresses from this server's network. Turn on only when everyone with an account is trusted, for example on a home or company server.
