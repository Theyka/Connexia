Private by design

Your snapshot is encrypted with AES-256-GCM using a key derived from your password — this server only ever stores ciphertext.

Zero-knowledge

Hosts, keys and snippets are encrypted on your device before upload. Even the server operator cannot read them.

Everywhere

Native apps for Windows, macOS, Linux, iOS and Android. Your terminal and SSH sessions follow you around.

Live sync

Changes push the moment you make them; every device pulls on start and re-syncs in the background.

Account security

TOTP two-factor authentication, scrypt password hashing and short-lived session tokens on every device.

Self-hostable

One static binary, no runtime dependencies. Runs anywhere — Docker, Coolify, a Raspberry Pi — on SQLite or Postgres.

Open source

Everything — app and server — is public on GitHub. Audit the crypto, build your own binaries, trust no black boxes.
